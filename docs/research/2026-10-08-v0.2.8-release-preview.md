与两项自然样本观察继续保留，未据此宣称模块或全部宿主验收完成。

   不覆盖已存在的 tag。GitHub Release 如需创建，另按明确授权的发布渠道执行。

## 宿主更新步骤（仅预览，未执行）

本次只读核对：Claude 的安装元数据为 0.2.7、scope=user；Codex 插件启用，marketplace
来源固定为 v0.2.7。下面是这两种现有安装的更新预览，不修改其他插件或全局规则。

Claude Code 沿用当前已登记的 marketplace：

```sh
claude plugin marketplace update tier-guard
claude plugin update tier-guard@tier-guard
```

Codex 当前固定 tag 来源不会自动跟随新发布。以下步骤适用于已核对为 tier-guard 固定 tag
来源的安装，只有 tag 已推送且用户确认后才执行：

```sh
codex plugin marketplace remove tier-guard
codex plugin marketplace add haigeerlab/tier-guard --ref v0.2.8
codex plugin add tier-guard@tier-guard
codex plugin list --available --json
```

固定 ref 更新步骤沿用[当前 README 中核对过的 CLI 0.160.0 接口](../../README.md#7-更新与卸载)。
跟踪分支的来源使用 marketplace upgrade 刷新后重新安装；不将它解释为修改固定 tag。
登记移除到重装完成期间来源不可用。插件列表用于确认版本与启用状态，CLI `/hooks`
用于信任审核；doctor 不能读取或证明信任。

确定实际新安装根与同一数据目录后，运行只读诊断；自定义配置显式传相同 `--config`：

```sh
python3 "$TIER_GUARD_PLUGIN_ROOT/hooks/tier_state.py" show --data "$TIER_GUARD_DATA_DIR"
python3 "$TIER_GUARD_PLUGIN_ROOT/hooks/tier_doctor.py" --data "$TIER_GUARD_DATA_DIR" --config /path/to/catalog.json
python3 "$TIER_GUARD_PLUGIN_ROOT/hooks/tier_report.py" --data "$TIER_GUARD_DATA_DIR" --config /path/to/catalog.json
```

上面两个变量是用户选择的真实安装根与数据目录，占位配置路径需替换。默认配置用户省略
`--config`。本次只读副本冒烟不授权付费派活、切换 auto 或调整宿主能力闸门。
