- Claude Code CLI `2.1.270`，`claude -p --model sonnet`，工具只放行 `Agent,Skill,Read`。

  并移除 `TIER_GUARD_MODE` / `TIER_GUARD_CONFIG` / `TIER_GUARD_LOG_DIR`，日志写入默认数据目录。
